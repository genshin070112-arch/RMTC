# decision_config.json 字段说明（v1.1）

[decision_config.json](decision_config.json) 是策略配置数据，由 `src/config.cpp` 读取。JSON 标准不支持注释；请把说明放在这里，不向实际文件加入 `//`、`/* */` 或额外说明字段。

实际默认内容：

```json
{"decision_type":"balanced"}
```

只有 `decision_type` 这一个字段，其值必须是以下已实现枚举之一：

| 值 | 含义 |
|---|---|
| `balanced` | 默认平衡策略，综合资源、任务、探索、战斗与风险 |
| `collect` | 阶段2资源候选收益乘1.15，仍比较当前战斗损失与防御收益 |
| `combat` | 阶段2资源候选收益乘0.85，接近攻击位的收益乘1.3；已有有效攻击时不重复奖励靠近 |
| `safe` | 提高威胁代价，偏重规避风险 |

具体行为以 `src/planner.cpp` 为准。修改须遵守赛前登记、裁判审批和暂停窗口等赛事要求；程序的格式检查不代表已获得裁判批准。程序每场限制策略变更次数。

本机 `run.sh` 通常读取工程下的这个配置；标准 launch 读取安装目录中的配置副本，修改源文件后应重新运行 `./build.sh` 以更新安装副本；容器启动脚本将工程 `config/` 挂载到容器。配置读取逻辑见 `src/config.cpp`，入口见《代码导航.md》。

v1.1 的奖励、扣除和任务收益已固化在 C++ 代码，不在此配置中添加数值参数；更新后的策略含义见 `docs/策略登记表.md`。
