## 八类事件如何处理

| 事件 | 程序消费模型结果后的行为 |
|---|---|
| 爆炸 | 按激活前可用步数提前多步撤离，路径与目标比较保留危险代价 |
| 幻术 | 按激活时合法位置历史推断命中或使用明确授予记录；效果跨离区/复活保留；只反转移动指令 |
| 天使恩泽 | 受伤时考虑模型公告的回血点；从成功移动回执推断入点，不把原地站立当触发 |
| 天下无双 | 在收益合适时去堡垒驻留；按连续驻留推断授予，5×5敌人范围攻击；效果到期清除 |
| 世界分裂 | 预避激活线、临时墙阻挡；到期移除期间新观察的临时墙记忆；不把晚加入位置当出生点 |
| 火爆辣椒 | 交点不作为自身必受伤害；可见敌车的主动入点分奖收益与风险比较；同批火线去重分奖，不把火线损血记为普通攻击贡献 |
| 洁身自好 | 比较反伤风险与防御可能分奖；上一帧defending只作为一种假设，与对方转攻击本车的假设取较差收益 |
| 潘潘的神 | 只有成功移动在获得窗口内才推断易伤，下一Tick开始，统一结束；增加近敌路径代价，不放大环境伤害 |

本地效果推断基于自己合法历史、成功回执和模型给出的事件参数；不读取裁判隐藏效果列表。错过公告/模型超时或错误时，不能保证还原全部事件状态，程序继续合法基础策略。

战术预测只覆盖可见车辆和两种对手假设，不是完整裁判仿真，不能保证对方动作、未来位置、未知火线或隐藏状态。独立探针与人工验收脚本不安装进参赛程序，也不向规划器提供管理数据。当前完整结果与未验证项见《自检报告.md》。

## 1.1.3 战术前瞻

同一套当前/下一Tick风险用于战术和目标移动，当前战斗死亡后不能靠移动或治疗复活；最后Tick不虚构后续战斗。普通直线与已知无双5×5采用不同几何，死亡敌人不进入未来风险。详细假设、回归和过拟合边界见《三次检查报告逐项处理.md》。

## 1.1.4 前瞻范围修复

健康期恢复即时收益比较；HP≤40保留生存前瞻。接近与巡逻交替不再重置无伤害退避。完整证据见《主要问题修复_1.1.4.md》和《自检报告.md》。
