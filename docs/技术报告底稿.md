# RMTC v1.1 技术报告底稿（应整理到语雀，非已提交材料）

## 整体设计

C++17/ROS2 Humble；机器人按“公开感知解析→合法状态记忆→事件模型结果→本地规划→合法动作构造→ROS发布→执行回执”运行。LLM仅负责理解自然语言事件和高层目标，libcurl线程与控制循环隔离；没有本地模型或逐Tick人工控制。

## 功能与方式

- 严格JSON、9×9坐标、动态地图/任务、场次和Tick缓存。
- 加权Dijkstra用cost排序、独立depth计算到达Tick并累计已知危险；资源、任务与战斗在比赛分尺度上比较，另有明确的生存偏好。阶段2对过时资源记忆降权。
- v1.1 的500点门槛、按比例贡献与60点批次分奖预测；每Tick先加奖再扣每次死亡60，真实D直接读感知。
- 战术评估比较攻击、防御与主动踩辣椒；按两种可见对手假设保守比较，不能保证对方真实动作。动态伤害任务独立于500封顶值，完成ID保留。
- 八种事件的模型输出校验、时效与已知自身效果推断。
- 网关超时、HTTP错误/重定向、配额、重试、去重、过期结果丢弃；格式错误最多追加2次重试，模型条目独立校验，官方关键感知仍严格校验。
- 分线程日志、可登记策略枚举、Docker多阶段编译与C++测试。

v1.1迁移和原始条款依据见《v1.1迁移说明.md》。具体实验数据请引用本轮自检报告，保留其“练习原始分、mock、真实LLM未验证”等限定，不改写成正式成绩或模型已成功理解。

## 问题与解决

1. ament_target_dependencies 与 target_link_libraries 混用签名导致CMake失败；统一调用形式后重建。
2. 重复感知覆盖429重试；先写测试复现，再按任务身份保留退避重试。
3. 中文长公告截断损坏UTF-8并丢失去重身份；保持UTF-8边界、使用完整公告身份去重，转发受限的近期内容并标记截断。
4. 晚加入位置误当出生点；仅开局或明确initial信息设置出生点，重启则从当前绝对位置继续。

5. 旧算法忽略互杀扣分、辣椒击杀和超过500的伤害任务；先通过三项回归复现，再将预测分数与真实分数分离，新增scoring/tactics模块。
6. 新版练习包的部分文字资料仍旧；以v1.1 PDF为依据，并用独立固定动作探针对照裁判二进制。任务预览分不能作为真实AI资格。
7. 用户审查发现动作收益提前返回、把加权cost当Tick、最后一步被排除等问题；按17个修复前失败的回归用例修正。详细判断、失败记录和证据见《检查报告逐项处理.md》《自检报告.md》。
