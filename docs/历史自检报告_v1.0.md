测量范围是解析回调开始到本地publish/日志入队，不含DDS排队、网络传输和裁判调度。单独的HTTP测试验证提交不等待模型，单工作线程避免并发失控；实际网络延迟仍须现场测。

恢复实验在Tick约18暂停/恢复、约48暂停并终止/重启本车，完成后同一进程换新session再跑一场，均执行到99、非法0；分别得分见recovery/results.json。容器默认Stage1实跑40/40、非法0、执行99、101帧、100次上一动作回执观测。

## 5. 发现并修正的问题

| 问题 | 根因与修复 | 修复前/后证据 |
|---|---|---|
| CMake配置失败 | ament使用plain链接签名，与PRIVATE签名混用；统一形式 | build_initial.log → build_final.log、colcon_build.log |
| 429重试丢失 | 重复感知在请求期间填入同公告pending，覆盖退避任务；按完整公告身份保留重试 | gateway_regression_RED.log中worker_retry失败 → final_recheck.log通过 |
| 长中文公告破坏UTF-8和去重 | 按字节截断且用截断文本识别完整公告；改为UTF-8安全边界和完整公告的有界身份去重，转发近期片段并标记截断 | gateway_regression_RED.log中long_utf8失败 → final_recheck.log通过 |
| 晚加入误认出生点 | 首次收到的位置并不等于初始出生点；只在Tick0/明确initial时登记 | spawn_regression_RED.log失败 → final_recheck.log通过 |
| CMake方式的包发现操作 | 直接CMake install不生成colcon根setup；增加activate.sh并验证CLI发现/launch，colcon仍使用其setup | ros_launch.log失败 → ros_launch_fixed.log正常 |

新Tick开始会清空旧缓存动作，防止异常规划后重复帧误发上一Tick动作；过旧的异步高层目标不继续采用，仍在有效期的事件事实独立按到期时间校验。

## 6. 未验证、未执行与使用限制

1. **真实LLM**：无自备API，真实代理调用、真实语义正确率、提示词对不同模型的表现、事件到动作的完整真实链路尚未验证。
2. **正式接入与资格**：正式模型/输出限制/新令牌、指定有线网络DDS发现、实际比赛设备、官方规则后续版本与检录需现场/赛前核实。本机同机测试不替代它们。
3. **全场景最优性**：测试地图与对手有限，没证明所有隐藏地图上都能高分，也没有保证胜率；关键收益、任务、基础战斗与回退是启发式。
4. **事件不完备信息**：晚加入、错过公告、模型拒绝/超时或错误时，不能保证恢复全部效果；程序只消费合法历史和校验后的模型事实，不会读取隐藏状态补齐。
5. **比赛程序性要求**：策略登记、人工切换审批及暂停窗口、代码版本确认、重启登记仍需队伍遵守，程序不能验证裁判批准。
6. **正式提交/个人理解**：仓库、镜像、语雀、问卷星未代上传；技术报告底稿须补自己的理解与分工，公开访问及提交回执未验证。
7. **容器覆盖**：镜像内部运行全部C++测试，DDS实跑为Stage1；完整Stage2实跑为本机二进制，未另跑容器里的完整500Tick四车Stage2。
8. **检查范围**：这不是形式化证明或全面安全审计；没有跨模型独立审查。已报告所有本轮执行命令中的实际失败及最终处理。
