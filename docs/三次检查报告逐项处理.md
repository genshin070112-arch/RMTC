## 下一Tick风险的准确含义

预测假设可见敌人留在原位置且能攻击，使用当前动作后仍存活敌人的HP；被本动作击杀的敌人不再制造未来威胁。当前战斗存活后，按已知已有天使/成功入点治疗估计下一Tick血量。同Tick多层回血不相加。沿用已有0.04/HP和死亡6的生存偏好，按损血占剩余血量的比例平滑衡量风险，没有新增地图坐标、敌人ID或固定低血量分段表。

这不是敌人行为真值，也不是多步最优搜索。敌人可能转向、追击、移动阻挡或获得未知效果，所谓脱离火线只针对已知几何和上述假设。最后一个动作Tick禁用未来风险，避免为不存在的下一回合放弃有效动作。

第一次前瞻实现把预测下一Tick死亡也用于“当前不防御就立刻死亡”的场景，导致已有即时防御测试失败。已修正为：当前普通移动无法生存时先比较即时自救；有移动余地才加入未来暴露代价。相关原测试重新通过，没有删除。

旧 `defense_competes_with_distant_resource` 原来硬性要求DEFEND。在新增前瞻下，存活着离开无双范围也可能是合理选择，因此改为验证“防御或确实走出5×5”，仍拒绝为资源走向仍受无双攻击的格子。这个测试约定的调整公开记录，不能把它描述成原断言未经变化就通过。

## 次要问题逐项判断

| 项目 | 处理与理由 |
|---|---|
| 堡垒 `< end` 边界 | **不改成 `<=`**。原规则：第十次驻留在本Tick战斗后授予；end Tick开始时效果失效。如果最后一次驻留在end−1完成，下一次可提交ATTACK的Tick正好是end，已经没有可用攻击窗口。现有严格边界合理。新增有/无一Tick攻击窗口对照。 |
| 本地48次成功预算 | 保留可配置的保守默认值，不以本轮练习分数擅自增大。新增实际48次HTTP成功、第49次被本地拒绝且未发送的测试。正式配额暂定100但以现场通知为准，可在赛前明确配置 `--llm-budget 100`；2xx但语义无效仍计费，不能靠重试绕过配额。 |
| partial被新公告覆盖 | 保留“新公告优先，旧provisional不提交”。其含义是宁可漏掉未确认事实，不把正在纠错的旧语义当真；当公告不包含历史时可能丢失事实，仍是已声明限制。不能简单恢复旧partial入库来换覆盖率。 |
| 资源年龄衰减 | 保留；只降权且重见刷新，不宣称视野外资源已消失。本轮没有按个别资源位置调衰减参数。 |
| 单条路径 | 保留有限记忆、单位置单候选路径限制；未声称获得全局最安全/最优搜索。 |
| 追逐8/12 Tick退避 | 保留上一版机制。本轮不根据某个练习对手重新调这两个数。 |

## 如何控制过拟合

1. 先用失败复现确定机制缺口，再写与坐标/方向/得分无关的规则实现。低HP组合测试涵盖144个变体，另有健康、当Tick致死、敌人被击杀、保护、无双/过期和末Tick对照。
2. 修改完成后固定策略，使用既有A/B场景及两个新地图种子20261025/20261026、C/D席位作对照；新地图同时运行留存的1.1.2和新版。没有看新地图成绩再调策略权重。完整数据见自检报告。
3. 新地图C初次因拾取点与静态墙重合被练习裁判拒绝。仅修正离线生成器的合法性约束；保留原失败记录，两个版本使用同一修正后地图。未按成绩换种子。
4. 不只看最终分数：同时检查非法动作、逐Tick回执、资源/对抗分和低HP用例。若分数有退步，照实报告。

这些措施降低只适配已有测试的风险，不能证明“没有过拟合”。两个新地图与固定陪练仍是小样本；真实模型事件、不同强度对手、异机和正式网络仍需后续验收。
