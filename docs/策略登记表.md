# v1.1 赛前策略登记表（待队伍向裁判正式登记）

文件统一为 `config/decision_config.json`，只允许 `{"decision_type":"某个枚举"}`。

| 枚举 | 已实现作用 |
|---|---|
| balanced | 综合资源/公开任务与500点门槛，比较攻击、防御、主动踩辣椒收益；考虑死亡扣60 |
| collect | 资源/资源任务候选收益乘1.15；仍计入当前Tick战斗损失与已知紧急风险 |
| combat | 资源候选收益乘0.85，伤害目标接近收益乘1.3；超过500仍考虑未完成伤害任务 |
| safe | 增加敌车攻击范围附近的路径代价，降低接敌候选优先级并增加附近路径代价；不把移动当作躲过本Tick攻击 |

共同约束：阶段1只有 move/wait；阵亡 wait；出生保护不 attack；tick/session从当前感知原样回填；事件只消费经校验的模型JSON。

同一场次程序最多应用两次人工枚举改变。合法切换须在暂停期间或加赛前，经裁判批准并登记；程序不能独立验证审批或暂停状态，切换窗口须人工遵守。不能夹带目标坐标、动作、Prompt、阈值或任意指令。接入参数更换按裁判通知，不属于临场算法调参。

v1.1新增规则已在封存前固化到 C++，不是允许临场新增的配置参数。`scoring`/`tactics` 输出是预测，真实 D 仍来自最新裁判感知。正式使用前须按此新版本重新登记、确认封存。

1.1.1修订：所有候选采用共同比赛分尺度，HP/死亡代价另作为生存偏好。资源记忆在阶段2随观测年龄降权。路径时间用实际步数，不用加权代价。重新启动进程会重置本地切换计数，队伍仍须遵守裁判跨重启累计登记的每场两次上限。

1.1.2修订：目标排序保留加权路径成本，累计HP风险不摊薄；已公告危险支持提前多步撤离。去掉无收益盲追及保护敌人的盲防；资源未满时未知区域探索参与收益比较。连续8步追逐而有效伤害无增长时暂停追逐12 Tick，已有有效攻击不受限制。治疗按可恢复血量和危急程度、堡垒按连续驻留进度/剩余时长/可见敌人估值。以上都是启发式偏好，不等于裁判计分或保证最优，详见本轮报告。

1.1.3修订：所有策略共享下一Tick的可见火线风险估计与撤离候选；普通攻击和无双使用各自范围，治疗按当前战斗后血量估值。没有新增临场可输入的数值参数；既有权重、预算默认值与追逐退避保持不变。预测假设与限制见《三次检查报告逐项处理.md》。

1.1.4覆盖上一条前瞻范围：仅HP≤40且当前移动可存活时启用下一Tick风险；健康期按即时战术估值。追逐中patrol仍累计无伤害时间。门槛固化在赛前代码，未新增现场可调参数。
